# SakuraKanji

Sakura-themed JLPT DB.

![Starting Screen](Frontend\public\assets\landingpage1.png) 

## Overview
SakuraKanji is a complete, interactive database for Japanese Kanji study. It features a minimalist, scroll-driven landing page that routes users through all JLPT levels (N5 to N1). 

## Features
* **Complete JLPT Database:** Fully integrated with a custom Supabase backend covering every JLPT level.
* **Detailed Character Data:** Accurately displays On'yomi and Kun'yomi readings, English meanings, and stroke order for all Kanji.
* **Interactive Motion UI:** A clean, scroll-animated frontend utilizing Framer Motion for a smooth, distraction-free experience.

## Tech Stack
* **Frontend:** React, TypeScript, Tailwind CSS
* **Motion:** Framer Motion
* **Backend / Database:** Supabase
